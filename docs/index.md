# Bienvenido al Dashboard de Métricas

Esta documentación detalla la arquitectura y el funcionamiento del nuevo módulo de métricas.

!!! note "Objetivo Principal"
    El propósito de este dashboard es unificar la visualización de datos de rendimiento en tiempo real para facilitar la toma de decisiones.
